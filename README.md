# LLM Prompting, Robustness, and Preference Learning

**Course:** CIS 5300 / HW7  
**Artifact type:** Course project / coursework

## Overview

Compared few-shot and chain-of-thought prompting, decoding settings, and prompt wording. Implemented Bradley-Terry probabilities, reward-model loss, and the DPO objective as course exercises, alongside preference-data analysis.

## Guiding question

How sensitive are language-model predictions to prompting and decoding, and how are preference-learning losses constructed?

## Methods and technical scope

Python; prompting; preference modeling; DPO loss.

## Evaluation and analysis

Compare reasoning and classification behavior across prompt variants and inspect preference annotations. Implementing a DPO loss is distinct from training an aligned model.
